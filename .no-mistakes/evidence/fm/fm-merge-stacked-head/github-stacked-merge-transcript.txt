FM_HOME is a marked lab home from bin/fm-lab-home.sh; the worker copy is a real git worktree
pushing to a real bare git remote; gh is a local stand-in that answers from that remote.
Lines starting with "$" are commands; "(forge)" and "(worker copy)" lines show real git state.
The lab home runs no watcher, so the guard's "WATCHER DOWN" banner is elided from script output.
